# OG Image for Social Sharing

## Required Image

Please create an `og-image.png` file (1200x630 pixels) for social media sharing previews.

### Specifications:
- **Dimensions**: 1200px × 630px (recommended ratio 1.91:1)
- **Format**: PNG or JPG
- **File name**: `og-image.png`
- **Location**: `public/images/og-image.png`

### Design Suggestions:
- Include "AnaEvaRec" branding
- Subtitle: "Web Security Header Analyzer"
- Author: "By Iftikhar Sanusi"
- Include a security shield or lock icon
- Use the brand colors (#4f46e5 - indigo)

### Tools to Create:
- Canva (https://www.canva.com)
- Figma
- Adobe Photoshop
- Online OG Image Generators

Once created, place the image at: `public/images/og-image.png`
